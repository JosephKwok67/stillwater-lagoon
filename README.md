# 钓鱼大冒险 · 静水泻湖 (Stillwater Lagoon)

一款吉卜力水粉手绘风格的 3D 俯视角治愈系钓鱼与海岸小镇生活游戏（Three.js + Vite + Blender 5.3 手绘烘焙资产）。

## 核心玩法与特色
- **双模式无缝漫游**：划着木船探索静水泻湖与 25 种生态游鱼，靠岸直接步入渔村石板小路、无缝推门进入室内（屋顶自动柔隐切开）。
- **六段式真实手感钓鱼**：按住蓄力抛竿 → 水下真鱼被饵吸引咬钩 → 张力进度遛鱼拉扯 → 收入随身鱼护或放生获得回响灵气。
- **自家红顶小屋**：内置 3D 活体生态大鱼缸（可随时放入/取出钓获的活鱼近景观赏）与红格小床小憩切换天气与昼夜。
- **小镇 NPC 与陪伴小狗**：渔市老板娘阿莲（高价收鱼）、渔具工匠老周（升级鱼竿与鱼饵）、灯塔守望者海伯（天气潮汐与传说鱼讯），以及全程伴游/跟跑的忠实小狗。

## 操作指南
| 按键 | 功能 |
| :--- | :--- |
| `W / A / S / D` | 划船 / 陆地行走（按住 `Shift` 奔跑） |
| `Space`（长按→松开） | 蓄力抛竿 / 咬钩提竿 / 按住收线遛鱼 |
| `E` | 码头上下船 / 开关木门 / 观赏家里大鱼缸 / 上床小憩 / 与 NPC 对话 |
| `B` | 打开随身鱼护 |
| 鼠标左键拖拽 / 滚轮 | 旋转与缩放镜头视角 |

## 本地运行
```bash
npm install
npm run dev
```
打开浏览器访问 `http://127.0.0.1:5173/` 即可游玩。

## 自动部署在线试玩（GitHub Pages）
本仓库已内置 [deploy-pages.yml](.github/workflows/deploy-pages.yml) 自动构建工作流。在 GitHub 仓库设置中进入 **Settings → Pages → Source 选择 `GitHub Actions`**，推送代码后即可生成公开在线链接，直接发给朋友点开浏览器就能玩！
