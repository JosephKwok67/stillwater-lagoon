# 《钓鱼大冒险 / 静水》项目方创意与长期构想备忘录（USER IDEAS）

> **用途**：专门存放项目方提出的核心玩法创意、中期迭代与远期扩展构想，每次新增想法都会及时追加记录，确保底层设计与美术规格始终为这些方向留好扩展空间。

---

## 一、日常核心体验（当前主线）
- **悠闲划船 + 赏景钓鱼**：在通透明亮的彩绘水体里划着红边木船慢悠悠钓鱼、看风景、与戴红领巾的小狗作伴。
- **丰富的鱼种与个体大小**：河湖内游动大量不同鱼种与不同体型的活鱼（同种鱼也存在普通 / 大物 / 王冠等真实体长差异），眼见为实下竿垂钓。
- **渔获去向双闭环**：
  1. **带回家放进室内大鱼缸饲养观看**（按真实捕获体型与物种在鱼缸里 3D 自由游动）；
  2. **卖掉换取贝币**（推进经济与装备/房产成长）。
- **真·无缝进出房屋**：不是黑屏传送切场景，而是可以**真实开关铰链木门直接走进走出**，室内由 Codex 后续用 Blender 精修每一栋建筑的内部空间，程序端做好全套室内外交互。
- **动作包与基础交互先行**：优先把上下船、岸上走路/小跑、推门进屋、钓鱼整套动作包和交互底座做扎实，再逐步接入多位 NPC。
- **NPC 对话与听觉过渡**：前期采用**立绘 + 打字机字幕对话**，不做复杂配音，可用类似《动森》风格的轻柔「嗯 / 唔 / 嘟」短拟声过渡，后期再决定是否接入完整环境音与音乐。

## 二、房屋成长、金钱交易与厨房做饭系统（2026-11-26 新增记录）
- **前期房屋策略**：前期保持现有临水红顶小屋的紧凑温馨尺寸不变，把基础交互、室内鱼缸和小憩流程打磨顺畅。
- **后期金钱交易与买大房子系统**：
  - 随着卖鱼（及后续种田/料理）攒下足够贝币，加入完整的**金钱交易与房产升级/购房系统**；
  - 玩家可以买下或扩建**更大的房子**（拥有更宽敞的客厅、更大容量甚至多座生态观赏鱼缸、更多家具摆设空间与独立房间）。
- **厨房与做饭系统（可后期随大房子解锁，或视节奏前期先加入轻度版本）**：
  - 升级后的大房子自带温馨**厨房区域**（灶台、切菜案板、炖锅、碗橱，同样支持无缝推门进屋交互）；
  - 玩家可以用钓到的新鲜鱼类（搭配后续种田产出的蔬菜/谷物/香料）烹饪海鲜料理（如烤真鲷、鲜甜鱿鱼串、金枪鱼盖饭、锦鲤茶泡饭等）；
  - 料理用途方向：
    - 摆盘展示 / 售卖获得比生鱼更高的收益；
    - 赠送给小镇 NPC（阿莲、老周、海伯）提升好感度并解锁隐藏鱼讯或配方；
    - 自己享用获得轻松增益（如临时延长抛竿距离、提高稀有大鱼咬钩率、加快步行速度等）。

## 三、后续规划：种田系统与渔农联动
- **向阳菜地已提前预留**：在玩家红顶小屋旁已经留好 **12 格向阳木框菜地** 及存档数据结构（`gameState.farmPlots`）。
- **基础种田循环**：翻土 → 播种 → 浇水 → 随「静水日历」天数自然生长 → 收获。
- **与钓鱼 & 做饭三向联动**：
  - 种出来的麦子、玉米、香草可以搓成**自制高级鱼饵**（吸引特定淡水/稀有鱼）；
  - 钓上来的水草、小虾或厨余可以做成**天然肥料**；
  - 新鲜鱼 + 菜地蔬菜直接送进**厨房做菜**，形成完整治愈的海滨田园生活闭环！

## 四、后续规划：完整畜牧业系统（2026-11-26 新增记录）
- **绘本 Q 版畜牧养殖场**：除了种田菜地外，在小镇向阳坡地或扩建后的大庄园旁开辟**木栅栏牧场与畜舍**，饲养一整套治愈系农场动物：
  - **小鸡与鸡舍**：每日下蛋，收集新鲜鸡蛋；
  - **奶牛与牧草坪**：喂草抚摸提升好感，收获香醇鲜奶；
  - **绵羊**：定期剪羊毛，用于出售换贝币或制作温馨布艺/家具装饰；
  - **小猪**：散步觅食、可发现松露等稀有林间食材。
- **渔 + 农 + 牧 + 厨四维联动**：
  - 鸡蛋、鲜奶、黄油 + 钓到的海鲜鱼类 + 菜地蔬菜瓜果 = 解锁更丰富的**大房子厨房料理食谱**（奶油香煎真鲷、海鲜蛋包饭、渔村浓汤、松露炙烤金枪鱼等）；
  - 畜产品与农作物同样接入渔村经济交易系统，攒钱购买更大房子、更多鱼缸与牧场扩建！
